# 화면 목록 & 플로우

## 가정 (스코프)
트래픽 버스트 = **이미 가입·로그인한 사용자들이 좌석 오픈을 기다리며 F5 연타**하는 상황. 따라서 **로그인/회원가입 화면은 설계하지 않는다**(트래픽 처리 어필과 무관). 인증은 입장 토큰 검증 위주로만 존재.

## 페이지 구성 (Figma)
빨간선(좌석선택 ↔ 주문확인)을 경계로 캔버스를 나눈다 — "좌석 잡기까지(읽기+점유)" vs "결제와 그 이후(쓰기 확정)".
- **03 · Screens — Discover & Seat**: 콘서트 목록 → 콘서트 상세 → ★대기열 → 좌석 선택
- **04 · Screens — Checkout & Result**: 주문 확인 → ★결제 처리중 → 결과(완료/실패/만료) → 마이페이지
- **05 · Flow**: 프로토타입 연결

## 핵심 플로우
```
콘서트 목록 → 상세(오픈 카운트다운) → [대기열] → 좌석선택(점유)
        → 주문확인 → [결제 처리중] → 결과(완료/실패/만료) → 마이페이지
```
★ = 트래픽 전략이 드러나는 화면(대기열=전략①, 좌석선택 점유=전략②, 결제 처리중=전략③).

## 화면 정의
| ID | 화면 | 페이지 | 목적 | 핵심 상태 |
|----|------|--------|------|-----------|
| P1 | 콘서트 목록 | 03 | 오픈 예정·진행중 노출 | 오픈전/오픈중/매진 |
| P2 | 콘서트 상세 | 03 | 일정·가격·예매 CTA | 오픈 카운트다운 |
| S2 | **대기열** | 03 | 순번·예상시간·진행바 | 대기중 / 입장가능 |
| P3 | 좌석/등급 선택 | 03 | 좌석 점유(hold) | AVAILABLE / HELD / SOLD |
| P4 | 주문 확인 | 04 | 수량·금액·약관 | 검증 |

## 콘서트 목록(P1) 정렬 규칙
- **1차 — 상태 우선순위**: 예매중 → 오픈예정 → 매진. (예매 가능한 것부터 위로)
- **2차 — 공연명 오름차순(asc)**: 같은 상태 내에서 이름순. 영문이 한글보다 앞(한국어 로케일 기본 collation 기준, 예: `NCT` < `뮤지컬`, `BTS` < `데이식스`).
- 데스크탑 5개/행 × 2행 = 10개(NOL 방식, 한 행 5개). 데모 10개 전부 한 화면에 노출 → **페이지네이션 없음**.
- 정렬 결과(10개): 예매중[NCT, 뮤지컬 위키드, 아이유, 잔나비, 콜드플레이, 혁오] → 오픈예정[성시경, 임영웅] → 매진[BTS, 데이식스].
- **데모 공연장은 2곳으로 통일**(P3 좌석맵과 정합): 인스파이어 아레나(뮤지컬위키드·아이유·잔나비·혁오·BTS) / KSPO DOME(NCT·콜드플레이·성시경·임영웅·데이식스).

## 좌석 선택(P3) 기능 명세
레이아웃: `AppBar` + 좌(구역맵→좌석, 메인) / 우(예약 패널, sticky) 2단. **P3 한 화면만**(주문확인은 다음 차례).

### 기준 공연장 (실사 기반)
데모 공연장은 **2곳**으로 고정 — 둘 다 무대 중심 보울(bowl) 구조라 같은 모델로 커버:
- **인스파이어 아레나(인천)** — 약 15,000석, 공연 전용. (기본 예시 venue)
- **KSPO DOME(올림픽체조경기장)** — 14,594석 / 최대 15,000. (블록 수만 다르게)
- 좌석 총 재고(~15,000)는 데이터 모델에 반영해 "오버셀 0" 수치 어필.

### 등급 ↔ 층/구역 모델
- 등급(tier): **플로어(스탠딩) / 1층 R석 / 2층 S석 / 3층 A석** (가격 차등). 예: 스탠딩 154,000 / R 143,000 / S 132,000 / A 110,000.
- 구역(block): 각 층을 블록으로 분할(예: 1층 101~108, 2층 201~210, 3층 301~310). 플로어는 좌석번호 없는 스탠딩 구역.
- 좌석(seat): 블록 내 `행×번`. 좌석 키 = `층-구역-행-번`.

### 레이아웃 (확정)
- **2단**: 좌(좌석선택 카드, 메인) / 우(예약 패널, sticky).
- 좌측 카드 안에 위→아래로 **구역맵 → 선택 구역 좌석 그리드 → 범례**.

### 좌측 — 구역맵 → 좌석 (한 카드 안, 위아래)
- `STAGE`(무대) 바 → 그 아래 **플로어(스탠딩) → 1·2·3층 구역 블록** 배치(보울). 매진 구역 블록은 dim.
- 구역 블록 클릭 → 그 아래 **좌석 그리드(행×번)** 가 펼쳐짐. **그리드는 좌측 카드 폭을 꽉 채움**(오른쪽 빈 공간 없이, 행을 카드 폭에 맞춰 분산).
- 헤더 "선택 구역: 1층 103구역 (R석)" + 하단 범례.
- 좌석 상태색 **3종**: 선택가능 / 선택됨(primary) / **선택 불가**(회색). 실제 티케팅(인터파크·NOL)처럼 구매자에겐 HELD를 따로 안 보여주고 SOLD와 합쳐 "선택 불가" 하나로. (HELD는 백엔드 점유락 상태로만 존재 — 아래 상태 머신 참고. 점유·오버셀 검증은 k6+Grafana+HPA 통계로 보지 사람이 보지 않음.)

### 우측 — 예약 패널(sticky)
- 미니 컨텍스트(공연 · 회차 19:00 · venue명).
- 등급/잔여 리스트(클릭 시 좌측 포커스): 스탠딩/R/S/A + 가격 + 잔여.
- 선택한 좌석 칩(예: "1층 103구역 · 5열 12번").
- **1인 최대 2매**: 2개 선택되면 추가 선택 비활성.
- 합계 금액(= 단가 × 매수).
- `Button/primary` "다음 (주문 확인)" → 클릭 시 좌석 점유(hold) 시작 + 7분 점유 타이머.

모델 요약: **스탠딩 = 구역+수량(좌석번호 없음), 지정석 = 구역맵에서 블록→좌석 직접 클릭**, 둘 합쳐 최대 2매. (상세의 "스탠딩 O석 · 지정석 O석" 잔여 표기와 일치.)

## 주문 확인(P4) 기능 명세
레이아웃: `AppBar` + 좌(상세) / 우(sticky 결제) 2단. 결제수단 선택 UI는 생략(약관 동의 + 결제하기만).
- 좌: **예매 정보 요약**(공연·일시·장소·좌석·매수) / **결제 금액**(티켓 단가×매수 + 예매수수료 장당 2,000×매수 + 배송료 0=현장수령 → 총 결제금액) / **약관 동의**(전체 동의 + 필수 3개: 예매·취소 규정 / 개인정보 수집·이용 / 개인정보 제3자 제공, `Checkbox` 재사용).
- 우 sticky: **좌석 점유 타이머**(P3에서 시작된 7분 hold 카운트다운) + 공연 요약 + 최종 결제금액 + `결제하기`(Button/primary).
- `결제하기` → 예매를 **Kafka로 비동기 발행(202 Accepted)** → 결제 결과(S5)로 이동.

## 결제 결과(S5 + R) 기능 명세
S5(처리중)와 R(결과)을 **한 화면 + 상태 블록 4 variant**로 통합. `AppBar` + 중앙 `StatusResult` 카드(상태 1개 표시). variant: processing / confirmed / failed / expired.
- **processing**: 로딩 + "결제를 처리하고 있습니다" + 주문번호. 폴링으로 결과 대기(버튼 없음).
- **confirmed**: 체크 + "예매가 완료되었습니다" + 주문 요약 + 마이페이지/홈.
- **failed**: "결제에 실패했습니다" + **좌석 유지**(점유 타이머 남음) + 다시 결제하기. (실패 ≠ 좌석 해제 — 아래 상태 머신.)
- **expired**: "결제 시간이 초과되었습니다" + 좌석 해제 + 다시 예매하기.

## 마이페이지(M) 기능 명세
스코프: **구매한 티켓(예매 내역) 확인 중심** (회원정보 수정·알림 등 제외). `AppBar` + 본문 + `Footer`(사용자가 인스턴스 삽입). 세로 오토레이아웃이라 위/아래 끼워넣기 쉬움.
- 본문: "예매 내역" 제목 + 총 건수 + **예매 행 리스트**.
- 행(BookingRow): 포스터 mini + 상태배지·주문번호 + 공연명·일시·장소 + 좌석·매수 / 우측 결제금액 + 보조 액션.
- 상태 3종: **예매완료**(success, "예매 취소" 버튼) / **관람완료**(neutral, 액션 없음 — 내역만) / **취소됨**(danger, "환불 완료"·제목/금액 흐리게). ※ 상세보기 같은 추가 화면은 스코프 밖이라 미구현(마이페이지는 헤더 프로필 버튼용 경량 화면).

## 상태 머신 (좌석 / 주문) — 중요
```
좌석:  AVAILABLE ─점유→ HELD(TTL N분) ─결제성공→ SOLD
                          └─(TTL 만료 / 사용자 취소)→ AVAILABLE
주문:  PENDING_PAYMENT → PROCESSING → CONFIRMED
                                   ├→ PAYMENT_FAILED  (좌석은 HELD 유지!)
                                   └→ EXPIRED         (TTL 만료 시에만 좌석 release)
```
- **결제 실패 ≠ 좌석 즉시 release.** 이미 "N분 안에 결제" 점유 타이머를 약속했으므로 그 타이머가 공정한 경계.
- 좌석 release는 오직 (a) 점유 TTL 만료, (b) 사용자 직접 취소.
- 확정(SOLD)은 **결제 성공 후에만**. 처리중에 미리 확정하지 않는다.

## 상태가 중요한 화면
### S2 대기열
- 대기중: "앞에 N명 · 예상 M분" + 진행바 + 이탈 경고. 폴링 2~3초.
- 입장가능: "지금 입장" CTA + 입장 토큰 만료 카운트다운. 만료 시 재대기 안내.

### P3 좌석 선택
- 점유 성공 → 주문확인(04)으로. 남은 점유시간 표시 시작.
- 점유 실패(이미 HELD/SOLD) → "매진/다른 좌석" toast.

### S5 결제 처리중 → 결과(R) 3갈래
- PROCESSING: 폴링/WS로 결과 대기.
- CONFIRMED: 예매 완료 + 주문번호.
- PAYMENT_FAILED: **좌석 유지** + "다시 시도/다른 결제수단" + 남은 점유시간 카운트다운.
- EXPIRED: 좌석 해제 안내(시간 초과).

## 상세(P2) 기능 명세
레이아웃: `wrapper`(좌/우 2단) — 좌측 `left`(타이틀 전체폭 → 포스터+스펙 → 탭 → 탭바디), 우측 `right`(BookingPanel).

### 캘린더 (관람일)
- 라이브러리: **react-day-picker (MIT, 무료)**. 우리 토큰 CSS로 스타일, `modifiers`로 선택일/주말 색, `disabled` matcher로 매진일 비활성. (헤드리스 대안: React Aria Calendar)
- **매진일 비활성**: 해당 날짜의 모든 회차 잔여=0 → 캘린더에서 선택 불가(disabled).
- 진입 시 **첫 예매가능 날짜+회차 기본 선택** → `예매하기` 기본 활성.
- `예매하기` 활성 조건 = 선택된 날짜+회차 잔여>0. 선택이 게이트라 버튼 disabled 로직 최소화.
- 전 회차 매진 시 = 모든 날짜 비활성 + `예매하기`는 "매진"(disabled).
- `예매하기` 클릭 → 대기열(S2) 진입.

### 우측 패널 (sticky)
- `right > BookingPanel`에 `position: sticky; top = AppBar높이 + 여백`. 스크롤 시 따라 내려옴.

### 탭 (공연정보 | 판매정보)
- 공연정보 = 이미지 1장(주최사 제공, NOL).
- 판매정보 = **Markdown 렌더**(`react-markdown` + `remark-gfm`). 하드코딩 표 대신 md 작성 → 렌더. 내용: ①상품 기본정보 ②예매취소조건(표) ③취소·환불 방법.

### 판매정보 콘텐츠 (md)
- **상품 기본정보**: 주최/기획 (주)제이와이피엔터테인먼트 · 고객문의 1544-1555 · 공연장소 KSPO DOME · 관람등급 만 7세 이상 · 예매수수료 장당 2,000원 · 배송료 현장수령 무료(배송불가)
- **예매취소조건**(관람일 기준 우선): 예매 후 7일 이내 = 없음 / 예매 후 8일~관람일 10일전 = 장당 4,000원(티켓금액 10% 한도) / 관람일 9~7일전 = 10% / 6~3일전 = 20% / 2~1일전 = 30%. ※ 예매 당일 밤 12시 이전 취소는 수수료 없음(예매수수료도 환불).
- **취소·환불 방법**: 마이페이지 > 예매내역 > 예매취소. 관람일 1일 전까지 가능, 공연 당일 취소·환불 불가.
