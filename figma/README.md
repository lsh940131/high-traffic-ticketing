# 🎨 figma — UI·UX 기획

"딱 필요한 만큼"의 화면만 정의한다. 티케팅의 본질 플로우(대기열 → 좌석 → 결제 → 결과)에 집중하고, 마케팅 페이지·마이페이지 등 부수 화면은 와이어프레임 수준으로만 남긴다.

실제 Figma 파일 링크는 작업 후 여기에 붙인다. 이 폴더의 문서는 Figma와 코드를 잇는 **단일 진실 소스(SSOT)**: 화면 목록, 플로우, 디자인 토큰, 컴포넌트 스펙.

## 파일
- [SCREENS.md](./SCREENS.md) — 화면 목록 & 사용자 플로우
- [DESIGN-TOKENS.md](./DESIGN-TOKENS.md) — 색·타이포·간격 토큰 (front와 1:1 매핑)
- [COMPONENTS.md](./COMPONENTS.md) — 컴포넌트 스펙

## Figma 작업 팁 (이 프로젝트 범위)
- 페이지: `01-Flow`(플로우), `02-Screens`(화면), `03-Components`(컴포넌트)
- 토큰은 Figma Variables로 만들고 DESIGN-TOKENS.md와 동일하게 유지
- 다크 1테마만. 라이트 테마는 범위 외
